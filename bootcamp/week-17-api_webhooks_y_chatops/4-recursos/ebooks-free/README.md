# 📚 Lecturas gratuitas — Semana 17

Ninguno es un manual de GitLab: son las fuentes de las ideas que la semana aplica. Todas gratuitas y accesibles sin registro. Comprobados en noviembre de 2026.

| Recurso | Qué aporta a esta semana |
|---|---|
| [Standard Webhooks — Specification](https://github.com/standard-webhooks/standard-webhooks/blob/main/spec/standard-webhooks.md) | Por qué la firma cubre `id.timestamp.cuerpo`, el prefijo `whsec_` y la ventana de tiempo. La base de la teoría 04 |
| [OWASP — Server Side Request Forgery Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html) | Qué evita bloquear la red local y por qué una lista de permitidos es mejor que una de prohibidos |
| [GraphQL — Pagination](https://graphql.org/learn/pagination/) | Cursores, `pageInfo` y por qué GraphQL pagina así |
| [Site Reliability Engineering — Eliminating Toil](https://sre.google/sre-book/eliminating-toil/) | Qué trabajo merece un bot y cuál no: el criterio para elegir qué automatizar |
| [RFC 9110 — HTTP Semantics, Status Codes](https://www.rfc-editor.org/rfc/rfc9110#name-status-codes) | La diferencia entre 401, 403 y 404 que la teoría 01 usa para leer errores |

> [!TIP]
> Si solo lees una cosa esta semana, que sea la especificación de Standard Webhooks: son dos páginas y explica cada decisión del receptor.
