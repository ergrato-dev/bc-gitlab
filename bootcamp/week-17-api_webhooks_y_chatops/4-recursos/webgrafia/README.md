# 🔗 Enlaces — Semana 17

Comprobados en noviembre de 2026 contra la documentación de GitLab 19.2.

## Los que vas a tener abiertos toda la semana

| Enlace | Para qué |
|---|---|
| [REST API](https://docs.gitlab.com/api/rest/) | Autenticación, paginación por desplazamiento y por claves, códigos de estado |
| [GraphQL API](https://docs.gitlab.com/api/graphql/) y su [referencia](https://docs.gitlab.com/api/graphql/reference/) | Cada tipo y campo de las consultas del auditor y de `estado`, y los límites de complejidad |
| [Group access tokens](https://docs.gitlab.com/user/group/settings/group_access_tokens/) y su [API](https://docs.gitlab.com/api/group_access_tokens/) | Crear, listar y rotar el token `auditor` |
| [Webhooks](https://docs.gitlab.com/user/project/integrations/webhooks/) | Eventos, cabeceras, `signing_token`, el registro de entregas y el reenvío |
| [Project webhooks API](https://docs.gitlab.com/api/project_webhooks/) | Crear, probar, listar entregas y reenviar por API |
| [GitLab ChatOps](https://docs.gitlab.com/ci/chatops/) y [Mattermost slash commands](https://docs.gitlab.com/user/project/integrations/mattermost_slash_commands/) | `run`, `CHAT_INPUT` y la sección `chat_reply` |

## Para cuando lo necesites

| Enlace | Para qué |
|---|---|
| [Webhook events](https://docs.gitlab.com/user/project/integrations/webhook_events/) | El cuerpo de cada evento, campo a campo |
| [Webhooks and insecure internal web services](https://docs.gitlab.com/security/webhooks/) | La red local, `outbound_local_requests_whitelist` y por qué no se abre entera |
| [CI/CD variables API](https://docs.gitlab.com/api/project_level_variables/) | `masked_and_hidden` y la actualización de `AUDITOR_TOKEN` |
| [Pipeline schedules API](https://docs.gitlab.com/api/pipeline_schedules/) | Crear la programación y `play` |
| [Rate limits](https://docs.gitlab.com/security/rate_limits/) | Qué limita la instancia y cómo se ve un `429` |
| [Standard Webhooks](https://www.standardwebhooks.com/) | La especificación de las cabeceras `webhook-id`, `webhook-timestamp` y `webhook-signature` que sigue GitLab |
