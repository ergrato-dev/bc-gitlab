# 🔗 Enlaces — Semana 05

## Los que vas a tener abiertos toda la semana

| Enlace | Para qué |
|---|---|
| [API de issues](https://docs.gitlab.com/ee/api/issues.html) | Filtros (`labels`, `milestone`, `not[]`, `issue_type`), `add_labels` y `remove_labels`, y `issues_statistics` |
| [API de etiquetas de grupo](https://docs.gitlab.com/ee/api/group_labels.html) | Donde vive tu taxonomía. Fíjate en que no hay campo `priority`: la prioridad es del proyecto |
| [API de tableros](https://docs.gitlab.com/ee/api/boards.html) | Tableros y listas. Los parámetros de configuración que ves marcados como Premium no existen en CE |
| [Acciones rápidas](https://docs.gitlab.com/ee/user/project/quick_actions.html) | La tabla completa, con el tier de cada acción. Úsala con `Ctrl+F` |

## Etiquetas y planificación

| Enlace | Para qué |
|---|---|
| [Etiquetas](https://docs.gitlab.com/ee/user/project/labels.html) | Grupo y proyecto, prioridad, promoción, suscripción, y la sección de *scoped labels* para saber qué se está sustituyendo |
| [API de etiquetas de proyecto](https://docs.gitlab.com/ee/api/labels.html) | `with_counts`, `include_ancestor_groups` y `promote` |
| [Hitos](https://docs.gitlab.com/ee/user/project/milestones/) | Proyecto y grupo, progreso y cierre. Las secciones de burndown están marcadas como Premium |
| [API de hitos](https://docs.gitlab.com/ee/api/milestones.html) | `include_ancestors`, `state_event`, y los issues de un hito |

## Tableros

| Enlace | Para qué |
|---|---|
| [Tableros de issues](https://docs.gitlab.com/ee/user/project/issue_board.html) | Qué hace cada movimiento entre listas. La tabla de "qué pasa al mover" es la que la teoría 05 resume |

## Plantillas y cierre

| Enlace | Para qué |
|---|---|
| [Plantillas de descripción](https://docs.gitlab.com/ee/user/project/description_templates.html) | Carpetas, plantilla `Default`, y los niveles de grupo e instancia marcados como Premium |
| [API de plantillas de proyecto](https://docs.gitlab.com/ee/api/project_templates.html) | El endpoint que usa el autograding para leer tus plantillas |
| [Patrón de cierre de issues](https://docs.gitlab.com/ee/administration/issue_closing_pattern.html) | El patrón por defecto, y cómo se cambiaría en `gitlab.rb` (no lo cambies en el laboratorio) |
| [Control de tiempo](https://docs.gitlab.com/ee/user/project/time_tracking.html) | Unidades, informes y la conversión día-horas |

| [Comparativa de tiers](https://about.gitlab.com/pricing/feature-comparison/) | Dónde está cada feature de planificación: epics, iteraciones, pesos, *scoped labels*, varios tableros de grupo |
