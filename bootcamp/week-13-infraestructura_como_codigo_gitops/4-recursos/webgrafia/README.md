# Webgrafia — Semana 13

- [Terraform GitLab Provider Documentation](https://registry.terraform.io/providers/gitlabhq/gitlab/latest/docs)
  Referencia completa de todos los recursos del provider oficial de GitLab para Terraform.

- [GitLab Managed Terraform State](https://docs.gitlab.com/ee/user/infrastructure/iac/terraform_state.html)
  Documentacion oficial del backend HTTP nativo de GitLab para remote state.

- [GitLab CI/CD for Terraform](https://docs.gitlab.com/ee/user/infrastructure/iac/)
  Guia oficial para integrar Terraform en pipelines de GitLab CI/CD, incluyendo el reporte del MR.

- [GitLab Kubernetes Agent Documentation](https://docs.gitlab.com/ee/user/clusters/agent/)
  Documentacion oficial completa del Kubernetes Agent: instalacion, configuracion, GitOps.

- [GitOps Working Group — OpenGitOps Principles](https://opengitops.dev/)
  Definicion formal de los cuatro principios de GitOps por la CNCF.

- [Terraform Language Documentation](https://developer.hashicorp.com/terraform/language)
  Referencia oficial de HCL: resources, modules, variables, state, import.

- [Open Policy Agent Documentation](https://www.openpolicyagent.org/docs/latest/)
  Documentacion de OPA y el lenguaje Rego para policy-as-code.

- [Conftest Documentation](https://www.conftest.dev/)
  Herramienta para testear archivos estructurados (como planes de Terraform) contra politicas Rego.

- [Minikube Documentation](https://minikube.sigs.k8s.io/docs/)
  Documentacion oficial de Minikube, reutilizada desde la semana 07.
