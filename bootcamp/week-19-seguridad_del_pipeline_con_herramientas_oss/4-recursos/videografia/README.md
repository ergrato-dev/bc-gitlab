# 🎥 Vídeos — Semana 19

Búsquedas, no vídeos concretos: las herramientas cambian de versión cada pocas semanas y un vídeo envejece antes que su búsqueda. Para cada una, qué tiene que tener el vídeo para que valga la pena. Comprobadas en noviembre de 2026.

## Escáneres

| Recurso | Canal | Por qué vale la pena |
|---|---|---|
| [Semgrep custom rules](https://www.youtube.com/results?search_query=semgrep+writing+custom+rules+metavariables+pattern-not) | Varios | Que escriba una regla desde cero con `pattern-not` y la pruebe. Si solo ejecuta `--config auto`, sáltalo |
| [Gitleaks git history](https://www.youtube.com/results?search_query=gitleaks+scan+git+history+secrets) | Varios | Que escanee el historial y no solo la carpeta, y que explique `.gitleaksignore` |
| [OSV-Scanner](https://www.youtube.com/results?search_query=osv-scanner+google+lockfile+vulnerabilities) | Varios | Que lea un lockfile y explique de dónde salen los avisos (osv.dev). Que sea de la versión 2 |
| [Trivy image scanning](https://www.youtube.com/results?search_query=trivy+container+image+scanning+ci+cache) | Varios | Que separe las CVE del sistema base de las de las dependencias del lenguaje, como la práctica 03 |
